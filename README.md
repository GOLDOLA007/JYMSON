# 💪 Workout Tracker

A web application to manage and track your weightlifting workouts, helping you monitor progress and control load progression over time.

## ✨ Features

- **User Authentication** - Secure login and registration system
- **Workout Management** - Create, edit, and delete workout routines
- **Exercise Tracking** - Log exercises with weight, reps, and sets
- **Progress Monitoring** - Track your strength gains and load progression
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **Session Management** - Automatic session handling with message notifications

## 🚀 Tech Stack

### Backend
- **PHP** - Core server-side logic
- **JSON** - Lightweight data storage
- **Session Management** - User authentication and state management

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with dark theme
- **JavaScript** - Dynamic interactions and DOM manipulation
- **Font Awesome** - Icon library for visual enhancements

## 📋 Prerequisites

- PHP 7.4 or higher
- Web server (Apache/Nginx)
- Modern web browser
